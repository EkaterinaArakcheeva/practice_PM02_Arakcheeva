#Ответы на вопросы

1. **ПМ.02 формирует компетенции в разработке программного обеспечения, проектировании баз данных, тестировании, работе с системами контроля версий.**

2. **Стек Python + MySQL + tkinter выбран за простоту, бесплатность и кроссплатформенность. Альтернативы: Java, C#, Qt, PostgreSQL.**

3. **ER-диаграмма - схема сущностей и связей в базе данных, нужна для правильного проектирования структуры данных.**

4. **Типы связей: 1:1, 1:N, M:N. Пример: один заказчик — много заказов (1:N).

5. **Git — система контроля версий. git commit сохраняет локально, git push отправляет на сервер.**

6. **Запустить python -m tkinter или проверить через скрипт — откроется окно, значит tkinter работает.**

7. **Меры безопасности: избегать мокрых рук, делать перерывы, обновлять ПО, соблюдать электробезопасность.**

8. **IP 127.0.0.1 — локальный адрес, означает текущий компьютер (localhost).**

9. **Добавить файл в Git: git add <файл>, затем git commit -m "сообщение", и git push.**

10. **README.md содержит описание проекта, инструкции по использованию и его назначение.**
